8. 验证 `/scan` 与地图墙体重合、`map -> base_link` 连续且安全锁均为 false。

### 7.2 平地闭环与误差（必须先完成）

1. 只规划验证当前位置→A、A→B、B→C、C→A；
2. 做 `30°～45°` 的 Nav2 自主转向复测，检查 `0.35 rad/s` 是否振荡或超调；
3. 分段执行当前位置→A、A→B、B→C、C→A；
4. 在地面标记真实起点和机身朝向线；
5. 每圈同时记录地图 TF 起终点和卷尺测得的真实位置/航向误差；
6. 至少重复 3 圈，分别保留成功、失败和人工接管记录。

误差指标：

```text
地图闭环位置误差 = sqrt((x_end-x_start)^2 + (y_end-y_start)^2)
地图闭环航向误差 = wrap(yaw_end-yaw_start)
真实位置误差     = 机身参考点相对地面起点标记的平面距离
真实航向误差     = 机身中心线相对起始朝向线的夹角
```

只用 AMCL/TF 不能代替真实地面测量，因为定位系统可能在回环后看似回到起点，
而机器人实体仍有偏差。

### 7.3 坡道测试（平地通过后）

1. 记录坡度、坡长、宽度、表面摩擦和上下坡方向；
2. 先用遥控器低速走查，确认 B2、雷达、里程计和网络不中断；
3. 首次自主测试只走直线短坡，不在坡面转向；
4. 先上坡，再单独测试下坡；每次只做一个方向；
5. 现场人员持遥控/急停，并在坡道两侧留出防跌落空间；
6. 记录俯仰角、定位连续性、路径误差、是否打滑和人工接管。

### 7.4 楼梯测试（最后进行）

当前平地 Nav2 的 `cmd_vel` 和二维代价地图不能证明具备自主上下楼梯能力。
开始楼梯测试前必须确认：

1. B2 官方支持的楼梯/特殊地形运动模式或步态及其切换方法；
2. 台阶高度、深度、宽度、平台和边缘防护；
3. 雷达/地图在楼梯几何上的可用性；
4. 遥控低速上下楼梯成功，并具备双人看护、急停和防跌落措施；
5. 不在楼梯边缘进行首次自主转向。

若上述任一条件未满足，2026-10-16 只能完成楼梯场景测量和遥控基线，不能把
自主上下楼梯写成已完成。
