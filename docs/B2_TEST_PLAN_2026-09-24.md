# B2 本周基本巡检链推进与 2026-09-24 实机测试方案

## 1. 事实标签

- **实机已验证**：PC 通过 Wi-Fi SSH 到 Jetson；Jetson 通过 Ethernet 接收 B2 状态；
  前进、后退、左右横移和 watchdog STOPMOVE；RoboSense 点云；前向 +X 和约 1 m

## 3. 明天必须在 Jetson+B2 上验证什么

所有步骤均要求现场有人看护、遥控器或急停可用、机器人周围无人员和线缆。每完成
一步保存输出再进入下一步。新代码部署方式需在本次 diff 确认后决定；不要覆盖 Jetson
现有未提交修改。

### 3.1 T0：恢复 Jetson 环境

PC：

```bash
ssh jetson@10.167.32.107
```

Jetson 的每个新终端：

```bash
export ROS_DOMAIN_ID=0
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export B2_NET_IF=enP8p1s0
export CYCLONEDDS_URI="<CycloneDDS><Domain><General><Interfaces><NetworkInterface name=\"${B2_NET_IF}\" priority=\"default\" multicast=\"default\" /></Interfaces></General></Domain></CycloneDDS>"
source /opt/ros/humble/setup.bash
source ~/unitree_ros2/cyclonedds_ws/install/setup.bash
cd ~/Unitree-B2-SLAM
source install/setup.bash
```

只读确认：

```bash
ros2 topic hz /lf/sportmodestate
ros2 topic echo /lf/sportmodestate --once
```

预期约 20 Hz，消息包含 `imu_state.quaternion`、`imu_state.rpy` 和 `yaw_speed`。

### 3.2 T1：先验证 yaw 数值和正负方向

先关闭闭环，仅以 1 Hz 打印四元数 yaw 与消息 RPY 的差值：

```bash
ros2 run b2_twist_bridge_py safe_motion_test --ros-args \
  -p yaw_hold_enabled:=false \
  -p yaw_status_log_sec:=1.0 \
  -p angular_speed:=0.10 \
  -p motion_pulse_sec:=0.30
```

检查顺序：

1. 保持锁定，观察静止 yaw 是否连续、是否突然跳变。
2. 现场净空后按 `i` 解锁。
3. 按一次 `q`，确认机头实际左转以及 quaternion yaw 的变化方向。
4. 按一次 `e`，确认实际右转和相反的 yaw 变化方向。
5. 按 `x` 停车，再按 `i` 锁定。

若 q/e 实际方向、yaw 符号或 quaternion 与 RPY 不一致，立即停止，不开启航向闭环，
保存终端输出。若 `0.10 rad/s` 只有腿部/重心动作而没有可确认转向，不得据此判断
符号错误；停车并重新启动，依次只把 `angular_speed` 提高到 `0.15`、最多 `0.20`
rad/s。`api_id=1034` 仍不得猜测含义。

### 3.3 T2：记录无航向保持的短脉冲基线

继续使用 `yaw_hold_enabled:=false`。在地面标记机头起始方向，分别只按一次：

```text
w 前进；s 后退；a 左移；d 右移
```

每次动作之间停车并重新对齐；保存程序打印的起止 yaw 变化。至少每方向 3 次，记录：
起始 yaw、结束 yaw、变化角度、实际位移、是否按时 STOPMOVE。

### 3.4 T3：航向保持短脉冲

只有 T1 符号正确、T2 自动停车正常后，重新启动：

```bash
ros2 run b2_twist_bridge_py safe_motion_test --ros-args \
  -p yaw_hold_enabled:=true \
  -p yaw_status_log_sec:=1.0 \
  -p yaw_kp:=0.60 \
  -p yaw_deadband_rad:=0.035 \
  -p yaw_max_correction:=0.10
```

按前进、后退、左移、右移顺序，每个方向先做 1 次，再做 3 次重复。任何一次出现反向
修正、振荡、持续转头、姿态数据超时或未按时停车，立刻按 `x`、锁定并停止测试。
结束日志会给出最大航向误差和最大修正角速度。若修正方向正确但 `0.10 rad/s` 没有
可见作用，先只把 `yaw_max_correction` 分级提高到 `0.15`、最多 `0.20 rad/s`；不要
当天同时修改 Kp、死区和上限，一次只改一个参数。

### 3.5 T4：启动运动 3D SLAM

创建独立目录：

```bash
mkdir -p ~/b2_maps ~/b2_bags
```

启动新数据库；Jetson 无显示时关闭可视化：

```bash
ros2 launch b2_slam_3d slam_3d.launch.py \
  delete_db:=true \
  database_path:=/home/jetson/b2_maps/b2_small_loop_20260924.db \
  use_rtabmap_viz:=false \
  cloud_topic:=/rslidar_points \
  odom_topic:=/odom \
  lidar_frame:=rslidar
```

另一终端必须先确认：

```bash
ros2 topic echo /b2_slam/preflight_ok --once
ros2 topic echo /b2_slam/preflight_report --once
ros2 run tf2_ros tf2_echo map base_link
```

`preflight_ok` 不是稳定 `true` 时禁止移动。通过后录包：

```bash
ros2 bag record -o /home/jetson/b2_bags/b2_small_loop_20260924 \
  /rslidar_points /lf/sportmodestate /lf/lowstate /odom \
  /b2_slam_3d/cloud_sync /b2_slam_3d/odom_sync /tf /tf_static
```

使用已通过 T3 的短脉冲控制或原厂遥控器走小范围低速闭合路线。观察：

```bash
ros2 topic list | grep cloud_map
ros2 run tf2_ros tf2_echo map odom
ros2 run tf2_ros tf2_echo map base_link
```

地图应随运动增长，不能出现明显双墙、撕裂、跳变或持续 ICP/TF 错误。

### 3.6 T5：保存并重新加载地图

RTAB-Map **仍在运行时**先确认二维地图实际话题：

```bash
ros2 topic list | grep -E '(^|/)map$'
```

若存在 `/rtabmap/map`：

```bash
ros2 run nav2_map_server map_saver_cli \
  -t /rtabmap/map \
  -f /home/jetson/b2_maps/b2_small_loop_20260924_2d
```

然后停止 rosbag，再对 SLAM 终端按 `Ctrl-C`，最后检查：

```bash
ls -lh ~/b2_maps/b2_small_loop_20260924.db
ls -lh ~/b2_maps/b2_small_loop_20260924_2d.*
ros2 bag info ~/b2_bags/b2_small_loop_20260924
```

重新加载同一三维数据库进行续建检查：

```bash
ros2 launch b2_slam_3d slam_3d.launch.py \
  delete_db:=false \
  database_path:=/home/jetson/b2_maps/b2_small_loop_20260924.db \
  use_rtabmap_viz:=false
```

不得再次使用 `delete_db:=true` 打开要保留的数据库。定位模式仍由
`autonomous_inspection.launch.py` 中的 RTAB-Map localization 配置提供，属于后续测试。

### 3.7 T6：稳定 LiDAR 前向距离

机器人保持静止，启动只读节点：

```bash
ros2 run b2_factory_inspection front_lidar_distance
```

另一终端：

```bash
ros2 topic echo /b2/perception/front_distance_report
```

依次把宽度足够的纸箱或泡沫板放在前方约 0.5、1.0、1.5、2.0 m，每个距离记录至少
10 秒。记录稳定距离均值、波动、有效帧比例、ROI 点数和距离簇点数。先调整地面高度
过滤，再调整点数和距离簇宽度；不得只根据一个样本改多个参数。

### 3.8 T7：前相机静止和运动采集

先只读保存 Jetson 上的源码和可执行文件清单：

```bash
find ~/b2_camera_test -maxdepth 2 -type f -printf '%p\n' | sort
```

继续使用此前已经验证成功的实际可执行文件，SDK2 动态库只对该进程设置：

```bash
LD_LIBRARY_PATH=/home/jetson/unitree_sdk2/thirdparty/lib/aarch64 \
  /home/jetson/b2_camera_test/<已验证的实际可执行文件>
```

不要照抄尖括号占位名称执行。先静止连续采集并保存，再在低速短脉冲运动中采集；检查
JPEG 是否可解码、分辨率是否保持 1920×1080、图像是否重复、模糊或丢帧。真实源码
拿回 PC 后再决定是整理为独立 SDK2 进程，还是增加 ROS2 压缩图像桥。
